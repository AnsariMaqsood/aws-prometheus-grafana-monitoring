# AWS Prometheus Grafana Monitoring

## Project Overview

This project implements AWS-based infrastructure monitoring and centralized Linux server log monitoring.

## Technology Stack

- AWS EC2
- Ubuntu Linux
- Grafana
- Prometheus
- Node Exporter
- Loki
- Grafana Alloy
